### 🕒 2026-09-02 10:44:41 UTC
***🎨***
**تبدیل ایده و اسکچ به رابط کاربری با هوش مصنوعی :**
***1️⃣***
Uizard :
اسکچ‌های دست‌ کشیده و وایرفریم‌ها را به رابط کاربری دیجیتال و قابل ویرایش تبدیل میکنه و برای ساخت سریع Prototype مناسبه.
[https://uizard.io](https://uizard.io/)
***2️⃣***
 Visily :
تصویر اسکچ، وایرفریم یا نمونه موجود رو به طراحی قابل ویرایش تبدیل میکنه و برای ساخت سریع UI و User Flow کاربردیه.
[https://www.visily.ai/](https://www.visily.ai/)
***3️⃣***
Google Stitch :
با توضیح متنی، تصویر یا وایرفریم، رابط کاربری برای وب و اپلیکیشن درست میکنه.
[https://stitch.withgoogle.com](https://stitch.withgoogle.com/)
***4️⃣***
Figma Make :
با توضیح متنی، رابط‌های کاربری ایجاد میکنه و برای ادامه طراحی و توسعه در اکوسیستم Figma مناسبه.
[https://www.figma.com/make](https://www.figma.com/make)
***5️⃣***
Banani :
ایده، متن یا تصویر را به طراحی UI تبدیل میکنه و با کمک Ai امکان اصلاح رو فراهم میکنه.
[https://www.banani.co](https://www.banani.co/)
***6️⃣***
UX Pilot :
برای تولید صفحات، رابط کاربری و User Flow با کمک هوش مصنوعی طراحی شده.
[https://uxpilot.ai](https://uxpilot.ai/)
***7️⃣***
Relume :
برای طراحی وبسایت کاربردیه، میتونه بر اساس ایده شما Sitemap و وایرفریم صفحات رو ایجاد کنه.
[https://www.relume.io](https://www.relume.io/)
***8️⃣***
v0 :
توضیحات متنی یا ایده شما را به رابط کاربری و کد قابل اجرا تبدیل میکنه.
[https://v0.dev/](https://v0.dev/)
***9️⃣***
Lovable :
با توضیح ایده، یک اپلیکیشن یا سایت قابل اجرا  درست میکنه.
[https://lovable.dev](https://lovable.dev/)
***🔟***
Galileo AI :
برای تبدیل توضیحات متنی به طراحی‌های UI با جزئیات دقیق مناسبه.
[https://www.usegalileo.ai](https://www.usegalileo.ai/)
