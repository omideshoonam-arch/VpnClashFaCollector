### 🕒 2026-09-21 11:26:14 UTC
**🤖معرفی 8 ابزار برای اجرای Local AI روی سیستم خودت :**
***1️⃣***
LM Studio :
یکی از ساده‌ترین راه‌ها برای اجرای مدل‌های مختلف به‌ صورت لوکال با رابط گرافیکی.
[https://lmstudio.ai](https://lmstudio.ai/)
***2️⃣***
Ollama :
یک Runtime سبک برای اجرای مدل‌های زبانی به‌صورت لوکال که مدیریت دانلود، اجرا و تعویض مدل‌ها رو ساده میکنه.
[https://ollama.com](https://ollama.com/)
***3️⃣***
Jan :
یک دستیار هوش مصنوعی اپن‌سورس برای دسکتاپ که اجرای مدل‌های لوکال و امکاناتی مثل Local API و قابلیت‌های Agent را ارائه میکنه.
[https://jan.ai](https://jan.ai/)
***4️⃣***
Open WebUI :
یک محیط شبیه ChatGPT که میتونی روی سیستم خودت اجرا کنی و مدل‌های Local مثل Ollama را داخلش استفاده کنی.
به‌جای کار با خط فرمان، یک رابط کاربری کامل برای چت، مدیریت مدل‌ها، کار با فایل‌ها و ... در اختیارت میگذاره.
[https://openwebui.com](https://openwebui.com/)
***5️⃣***
AnythingLLM :
برای کار با فایل‌ها و اسناد شخصی فوق‌العاده کاربردیه.
[https://anythingllm.com/](https://anythingllm.com/)
***6️⃣***
Msty Studio :
مناسب برای مدیریت مدل‌ها و ساخت Workflowهای AI
[https://msty.app](https://msty.app/)
***7️⃣***
Pinokio :
یک لانچر برای نصب و اجرای تعداد زیادی پروژه اپن‌سورس در حوزه AI، بدون اینکه برای هر پروژه درگیر نصب دستی dependencyها بشی.
[https://pinokio.computer](https://pinokio.computer/)
***8️⃣***
ComfyUI :
یک سیستم Workflow قدرتمند برای اجرای مدل‌های تولید تصویر، ویدیو، صدا و پروژه‌ های چندمرحله‌ای به‌صورت لوکال.
[https://www.comfy.org](https://www.comfy.org/)
