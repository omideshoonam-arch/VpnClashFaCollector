**📱9 ابزار کاربردی برای تحلیل امنیت یک فایل APK قبل از نصب :**
 
***1️⃣***
Google Play Protect :
ابزار امنیتی داخلی اندروید که اپلیکیشن‌های نصب‌ شده رو حتی اگر از خارج گوگل‌پلی دانلود شده باشن رو بررسی میکنه. 
***🔗***
 
[https://support.google.com/googleplay/answer/2812853](https://support.google.com/googleplay/answer/2812853)
***2️⃣***
VirusTotal :
یکی از مهم‌ترین سرویس‌ها برای بررسی فایل‌های مشکوک. فایل APK رو با چندین موتور امنیتی و آنتی‌ویروس بررسی میکنه و نتایج شناسایی بدافزارها رو نمایش میده.
***🔗***
 
[https://www.virustotal.com/gui/home/upload](https://www.virustotal.com/gui/home/upload)
***3️⃣***
Exodus Privacy :
برای شناسایی ردیاب‌های موجود در اپلیکیشن‌ها، به‌خصوص SDKهای تبلیغاتی، تحلیلی و جمع‌آوری اطلاعات.
***🔗***
 
[https://reports.exodus-privacy.eu.org/en/](https://reports.exodus-privacy.eu.org/en/)
***4️⃣***
LibChecker :
یکی از بهترین گزینه‌ها برای شناخت اجزای داخلی اپلیکیشن.
***🔗***
 
[https://github.com/LibChecker/LibChecker](https://github.com/LibChecker/LibChecker)
***5️⃣***
App Manager :
یک ابزار اپن سورس و پیشرفته برای بررسی اپلیکیشن‌های نصب‌ شده روی اندروید. بررسی مجوزها و امضای دیجیتال، مشاهده Activity، Service و Receiver.
***🔗***
 
[https://github.com/MuntashirAkon/AppManager](https://github.com/MuntashirAkon/AppManager)
***6️⃣***
MobSF | Mobile Security Framework :
یکی از کامل‌ترین فریم‌ورک‌های اپن‌سورس برای ارزیابی امنیت اپلیکیشن‌های موبایل، مناسب توسعه‌دهندگان و تحلیل‌گران امنیت.
***🔗***
 
[https://github.com/MobSF/Mobile-Security-Framework-MobSF](https://github.com/MobSF/Mobile-Security-Framework-MobSF)
***7️⃣***
Koodous :  
یک پلتفرم تخصصی و جامعه‌محور برای پژوهش و تحلیل بدافزارهای اندرویدی.
***🔗***
 
[https://koodous.com/](https://koodous.com/)
***8️⃣***
Pithus :
یک پلتفرم اپن‌سورس برای تجمیع و تحلیل امنیتی اپلیکیشن‌های اندروید با استفاده از چند ابزار تخصصی. استفاده از ابزارهایی مانند APKiD و Quark، بهره‌گیری از MobSF و AndroGuard
***🔗***
 
[https://beta.pithus.org/](https://beta.pithus.org/)
