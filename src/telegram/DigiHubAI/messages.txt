**دسترسی رایگان به API چند مدل هوش‌مصنوعی با AMD :**
شرکت AMD از طریق برنامه توسعه‌دهندگان خودش، سرویس Token Lab رو برای دسترسی به API چند مدل هوش مصنوعی فعال کرده.
با ثبت‌نام رایگان میتونی بدون نیاز به کارت بانکی، یک API Key با 10 واحد اعتبار رایگان دریافت کنی که 30 روز اعتبار داره.
***🔹***
 مدل‌های قابل دسترسی :
- DeepSeek V4.1 Flash
- GLM 5.3 Flash
- Qwen 3.8 (27B و Flash Next)
- Gemma 4 (31B IT)
***🔸***
نحوه دریافت و استفاده :
***1️⃣***
 از طریق لینک زیر وارد برنامه AMD AI Developer Program شو و ثبت‌نام کن.
***2️⃣***
 وارد Token Lab شو و API Key اختصاصی خودت رو بساز.
***3️⃣***
 کلید رو در ابزارهای مناسب با تنظیمات OpenAI Compatible وارد کن.
﻿

`https://api.tokenlab.amd.com/v1`

***🔹***
نتیجه این آزمایش بازی Saltline هست :
-بازی در یک بندر کانتینری بارانی جریان داره، بازیکن باید سه مرکز ارتباطی را از کار بندازه و از پهپادها و ربات‌های دشمن عبور کنه و خودش رو به محل استخراج برسونه.
-تمام محیط سه‌بعدی، مدل‌ها، تکسچرها و صداها از طریق کدنویسی تولید شدن، حتی از تصاویر و مدل‌های سه‌بعدی آماده استفاده نشده.
