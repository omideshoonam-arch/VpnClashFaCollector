 امکانات:
***🔑***
 ساخت کلید جدید با یک کلیک (با چند API و تعویض خودکار هنگام ریت‌لیمیت)
***📥***
 ایمپورت فایل JSON ابزار usque یا روش دستی
***📱***
 خروجی برای Clash، v2rayNG، Happ، Streisand، Shadowrocket، MahsaNG و ...
