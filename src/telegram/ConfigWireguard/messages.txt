### 🕒 2026-09-10 13:25:15 UTC
**Automate V2Ray Config Collector**
پایپ‌لاین خودکار جمع‌آوری، اعتبارسنجی و انتشار کانفیگ‌های V2Ray/Xray از منابع عمومی. این پروژه با Python 3.12 نوشته شده و از یک سیستم تست دو مرحله‌ای استفاده می‌کند: ابتدا فیلتر سریع TCP با ۱۰۰ worker همزمان، سپس تست واقعی با Xray-core که برای هر کانفیگ یک instance موقت اجرا کرده و از طریق SOCKS5 درخواست HTTP واقعی ارسال می‌کند. فقط کانفیگ‌هایی که latency آن‌ها زیر threshold باشد منتشر می‌شوند.
خروجی‌ها هر ۲ ساعت از طریق GitHub Actions به‌روزرسانی شده و شامل فایل‌های جداگانه بر اساس پروتکل، کشور و نوع شبکه هستند. پروژه تحت مجوز MIT منتشر شده است.
