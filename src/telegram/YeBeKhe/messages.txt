### 🕒 2026-07-11 06:30:50 UTC
اضافه کردن Node ها تو پنل نهان هیچ چیز عجیب غریبی نداره. 
***🛠️***
***✨***
اول شما باید حداقل دو تا پنل نهان داشته باشید. 
***🔢***
یک پنل به عنوان مرکز 
***🏠***
، یه پنل به عنوان Node. 
***🌐***
تو پنلی که قراره به عنوان Node اضافه بشه، وارد تب «تنظیمات پایه یا System» بشید و از قسمت «کلید API پنل» یک کلید میسازید 
***🔑***
 و کلید ساخته شده رو کپی می‌کنید. 
***📋***
حالا وارد پنلی که قراره به عنوان مرکز استفاده بشه بشید و تو تب «پیشرفته یا Advanced» 
***🚀***
 از قسمت «سایر نودها» روی کلید «افزودن نود» کلیک کنید. 
***👆***
تو فیلد «آدرس نود» لینک ورکری که ازش API گرفتید رو ثبت کنید، برای مثال:
[kmkh.trump.workers.dev](http://kmkh.trump.workers.dev/)
حتما بدون https و بدون هیچ پارامتری در انتهای لینک. 
***🚫***
***🔗***
و تو فیلد «کلید API» همون کلیدی که از ورکر دیگه تون دریافت و کپی کردید رو قرار بدید 
***🔐***
 و روی «افزودن نود» کلیک کنید. 
***✅***
حالا روی «ذخیره تنظیمات» کلیک کنید 
***💾***
 و اتصال دو پنل به هم تکمیل میشه. 
***🔗***
با این کار شما کافیه تو پنل مرکز تنظیماتی که دوست دارید اعمال و ذخیر کنید، برای کاربراتون تو اینک اشتراکشون کانفیگ هایی با تموم نود های اضافه شده یا نود های انتخابی شما و تنظیمات پنل مرکز ساخته میشه. 
***🎛️***
***📲***
